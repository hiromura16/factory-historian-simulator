01-normal

正常 / 4設備 / 過去1000時点 · JSONをダウンロード

  • 想定　期間指定、品質コード、欠測、集計と過去値取得の検証。4設備 / 過去1000時点を想定。
  • 生成内容・条件　更新周期1000ms、最大tick数無制限。 4設備×valueを1秒間隔で保存。過去1000時点を初回に作成し、その後1tickに1時点ずつ追加。保持90日。
  • 確認事項　rawの時刻・値・品質を照合し、同時刻の複数サンプルもカーソルで取得。 mean/min/max/sum/count/last、Goodのみの集計、欠測補完none/null/previousの違いを確認。欠測は0として扱わない。
  • 実行前　公開・認証・送信先は別のプロファイルで指定し、保存後に停止・開始して適用。各条件はフォームとJSONで編集可能。
